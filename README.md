# Напоминалка

Простое приложение-напоминалка для Windows 10/11 на Python: интерфейс на tkinter,
хранение в SQLite3, всплывающие окна поверх всех окон и системные уведомления
(toast). Уведомления приходят даже если главное окно свернуто.

## Возможности

- Добавление напоминаний: заголовок, описание, дата и время срабатывания
- Повторяющиеся напоминания: каждые N минут, часов, дней, недель, месяцев
  или лет; после срабатывания автоматически переносятся на следующий раз
- Статусы напоминаний: **Ожидает**, **Готово**, **Просрочено**, **Отменено**
- Автоматический перевод сработавших напоминаний в статус «Просрочено»
- Уведомления при наступлении времени:
  - системный toast (через `winotify`, резервно `win10toast`);
  - popup-окно поверх всех окон с кнопками «Готово», «Отложить 5 мин», «Закрыть»
- Отметка напоминания как «Готово» или «Отменено»
- Удаление напоминаний (с подтверждением)
- Просмотр списка с фильтром по статусу и подсветкой (просроченные — красным)
- Счётчики напоминаний по статусам в строке состояния
- Работа в свёрнутом виде: планировщик на `root.after` продолжает проверять
  время срабатывания, пока запущен mainloop tkinter

## Требования

- Windows 10/11
- Python 3.10+ (проверено на 3.15)
- `winotify` — устанавливается из `requirements.txt` (необязательно, но
  рекомендуется; без него останутся popup-окна)

## Установка и запуск

```powershell
git clone https://github.com/Konst124/reminder-app.git
cd 4
python -m pip install -r requirements.txt
python app.py
```

База данных `reminders.db` создаётся автоматически рядом с файлами проекта
при первом запуске. Таблица и индексы создаются, только если их ещё нет.

## Структура проекта

```
├── app.py            # Главное окно (tkinter), диалог добавления, планировщик проверок
├── db.py             # Слой SQLite3: создание таблиц, CRUD, фильтры, поиск сработавших
├── notifications.py  # Toast-уведомления (winotify/win10toast) и popup поверх всех окон
└── requirements.txt  # Зависимости
```

## Как это работает

1. При старте `db.py` проверяет наличие таблицы `reminders` и создаёт её
   при необходимости.
2. Каждые 5 секунд (`app.py`, `check_due`) приложение ищет напоминания
   в статусе «Ожидает», время которых наступило и которые ещё не показывались.
3. Найденные напоминания помечаются как показанные (`notified = 1`,
   защита от повторных уведомлений), по ним отправляется toast и открывается
   popup. Дальше два варианта:
   - обычное напоминание переводится в статус «Просрочено»;
   - повторяющееся автоматически переносится на следующий интервал
     и остаётся в статусе «Ожидает» — серия продолжается, пока напоминанию
     не выставят «Готово» или «Отменено».
   Если приложение было закрыто несколько периодов подряд, пропущенные
   срабатывания схлопываются: перенос выполняется сразу на ближайший
   будущий интервал и уведомление приходит один раз.
4. Кнопки popup и панели инструментов меняют статус в БД: «Готово»
   закрывает напоминание (для повторяющегося — останавливает серию),
   «Отложить 5 мин» возвращает его в «Ожидает» со сдвигом времени
   срабатывания.

## Схема базы данных

Таблица `reminders`:

| Поле          | Тип     | Описание                                      |
|---------------|---------|-----------------------------------------------|
| `id`          | INTEGER | Первичный ключ (AUTOINCREMENT)                |
| `title`       | TEXT    | Заголовок (NOT NULL)                          |
| `description` | TEXT    | Описание, по умолчанию пустое                 |
| `trigger_at`  | TEXT    | Дата и время срабатывания, `YYYY-MM-DD HH:MM` |
| `status`      | TEXT    | Ожидает / Готово / Просрочено / Отменено      |
| `notified`    | INTEGER | 1 — уведомление уже показано                  |
| `repeat_every`| INTEGER | Интервал повтора (0 — не повторяется)         |
| `repeat_unit` | TEXT    | minutes/hours/days/weeks/months/years, `none` |
| `created_at`  | TEXT    | Дата и время создания записи                  |

Индексы: `idx_reminders_status` (по статусу), `idx_reminders_trigger`
(по времени срабатывания).

Миграция: если база создана старой версией приложения, колонки
`repeat_every` и `repeat_unit` добавляются автоматически при первом
запуске (`ALTER TABLE`), существующие данные сохраняются.

## Формат даты и времени

При добавлении напоминания дата и время вводятся в формате
`ГГГГ-ММ-ДД` и `ЧЧ:ММ` (например, `2026-12-31` и `18:30`).
Если указано прошедшее время, приложение предупредит: напоминание
сразу станет просроченным.

Для повторяющихся напоминаний отметьте «Повторять» и укажите интервал
(например, `1` + `дней` — ежедневно). Календарные интервалы учитывают
длину месяцев и високосные годы: 31 января + 1 месяц → 28 (29) февраля.
